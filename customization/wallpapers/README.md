# NekoDevOS Wallpapers

This directory contains anime-themed wallpapers for NekoDevOS.

## Directory Structure

```
wallpapers/
├── default/          # Default wallpapers that come with the distro
├── anime/            # Anime character wallpapers
├── landscape/        # Anime landscape/scenery wallpapers
├── minimal/          # Minimalist anime-themed wallpapers
└── seasonal/         # Season-themed wallpapers
```

## Adding Wallpapers

1. Place your wallpapers in the appropriate subdirectory
2. Recommended formats: PNG, JPG, WEBP
3. Recommended resolution: 1920x1080 or higher
4. Ensure you have proper rights/licenses for any images used

## Automatic Wallpaper Rotation

To enable automatic wallpaper rotation, use the included script:

```bash
~/scripts/setup-wallpaper-rotation.sh
```

## Sources

Remember to respect copyright and only use:
- Original artwork with permission
- Creative Commons licensed images
- Public domain images
- Legally purchased wallpapers

## Popular Anime Wallpaper Websites

- WallpaperCave (Free)
- Wallhaven.cc (Free, Creative Commons)
- DeviantArt (Check licenses)
- Pixiv (Requires account, check artist permissions)
- Unsplash (Free, high-quality landscapes that could work)

## Creating Custom Wallpapers

You can create anime-themed abstract wallpapers using:
- GIMP
- Inkscape
- Blender (for 3D anime-style renders)
- AI tools (ensure proper licensing)

**Note:** This repository does not include copyrighted wallpapers by default. Users should add their own wallpapers after installation.
